# Mneme 3.6.0

Mneme 3.6.0 is a reliability, security, privacy, retrieval-contract, and release-engineering upgrade produced through ten complete engineering loops.

## Highlights

- MCP client schemas are generated from the runtime Zod contracts, eliminating manual schema drift.
- Cross-scope retrieval requires an explicit `scope: "*"` caller opt-in.
- Tree-sitter compatibility is checked before native parsing calls, preventing unsupported ABI combinations from terminating the process.
- State readers and public MCP inputs have explicit resource bounds.
- Python and Node coverage gates, artifact installation smoke tests, security contracts, and release invariants are active in CI.
- Retrieval, privacy, benchmark, architecture, and competitive claims now distinguish shipped, opt-in, gated, experimental, and roadmap behavior.
- Mneme exposes a machine-readable runtime capability report.
- The full engineering evidence is recorded in `docs/MNEME_TEN_LOOP_ENGINEERING_REPORT.md`.

## Compatibility

Markdown remains the durable ground truth. Vault and derived-index formats are unchanged. No data migration is required.

A caller that intentionally needs cross-scope retrieval must now send `scope: "*"` explicitly. Inputs above documented safety limits are rejected before processing.

## Verification

The release candidate is gated by Python 3.11 through 3.14, Node 22 and 24, Linux, macOS, and Windows matrices, strict type checks, package tests, parity tests, CodeQL, repository integrity checks, plugin validators, package artifact smoke tests, and seeded benchmark regression guards.

Synthetic benchmark results remain labelled synthetic and are not presented as real-world superiority evidence.
