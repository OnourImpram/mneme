What it is

Your vault stays the source of truth

mneme is an open-source memory layer for Claude Code and any MCP client. Your Markdown vault remains authoritative. Everything derived from it — the search index, embeddings, knowledge graph, and summaries — is rebuildable and never authoritative. Nothing is locked into a proprietary store.

Invariant 01

Markdown is the source of truth

All memory lives in plain Markdown files you own. Derived stores are rebuilt from the vault, not the other way around.

Invariant 02

No LLM on the Stop or critical path

Capture is deterministic. p95 latency is around 3 ms on the seeded benchmark. Nothing waits on a model call during session hooks.

Invariant 03

Redaction before every derived store

A user configuration can never weaken a built-in privacy mode. Redaction runs before content reaches any index, embedding, or graph.

Install

Get started

Choose the package that matches your client. All packages are independent; install only what you need.

Claude Code plugin Recommended
pipx install mneme-cc-plugin && mneme install

Installs hooks, skills, and the MCP server automatically via mneme install.

Core engine
pip install mneme-core

Low-level engine: indexing, retrieval, privacy, graph, and benchmarks.

MCP server — any MCP client
npm install -g mneme-mcp-server

Provides the mneme-mcp command. Works with any MCP-compatible client.

MCP Registry

Listed on the official MCP Registry

mneme is listed on the official MCP Registry as io.github.TheGoatPsy/mneme. The MCP Registry is the canonical, project-maintained directory of Model Context Protocol servers, so any MCP client can discover and install mneme from a single verified source instead of a random GitHub link.

The io.github.TheGoatPsy namespace is bound to the GitHub account that owns the project, so the entry is ownership-verified, not self-asserted.
