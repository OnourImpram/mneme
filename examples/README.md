# Examples

Working reference materials for users adopting mneme.

## Contents

- `vault-skeleton/`: a clean room reference vault structure showing the standard layout (sessions/, topics/, references/, inbox/, .mneme/). Copy this as a starting point and replace contents with your own.

## Cookbook

For full transcripts demonstrating mneme workflows, see `docs/COOKBOOK.md` at the repository root.

## Contributing Examples

Open a pull request adding your example as a directory under `examples/`. Include a `README.md` that explains what the example demonstrates, the install profile required, and any expected output.
